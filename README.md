# NEED Wiki website (static version)

A static copy of the NEED RO wiki.

## Notes

- **Copyright.** The wiki belongs to the NEED team. Check with them before publishing a public copy.
- **Size.** Check the size of the `data` folder after step 1. Cloudflare Pages allows 20,000 files per site and 25 MB per file, and this should be well within both.
- **Updates.** The site only changes when you download and upload again. Nothing refreshes automatically.
- **Korean.** The site defaults to English and falls back to Korean for articles without an English version.
